# Source Code

This directory contains reusable Python modules for RetailPulse AI.

## Planned modules

- `data_processing.py` — data loading, validation, and cleaning
- `analytics.py` — sales KPIs and business metrics
- `customer_segmentation.py` — RFM analysis and customer segments
- `forecasting.py` — sales forecasting and model evaluation
- `visualizations.py` — reusable Plotly charts

## Development principles

- Keep functions modular and reusable.
- Validate inputs and handle missing data carefully.
- Document important assumptions and business rules.
- Separate data processing, analysis, modelling, and presentation.
- Test calculations before using them in the dashboard.

Implementation will be added and tested incrementally.
