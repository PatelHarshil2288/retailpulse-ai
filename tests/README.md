# Testing

This directory contains automated tests for RetailPulse AI.

## Planned tests

- Data loading and schema validation
- Missing values and duplicate handling
- Cancellation and invalid transaction filtering
- Revenue and KPI calculations
- Customer RFM metrics and segmentation
- Forecast evaluation
- Dashboard input validation

## Testing principles

- Test calculations against known expected results.
- Cover empty datasets and unusual input values.
- Validate assumptions before reporting analytical results.
- Run tests before publishing important changes.

Tests will be implemented alongside the corresponding application modules.
