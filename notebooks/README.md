# Exploratory Data Analysis

This directory will contain the notebooks used to explore and understand the retail transaction dataset.

## Planned analysis

- Dataset structure and data types
- Missing values and duplicate records
- Invoice and transaction patterns
- Revenue and quantity distributions
- Monthly and seasonal sales trends
- Product and country performance
- Customer purchasing behavior
- Data quality findings and cleaning decisions

## Analytical approach

Each notebook will document its objectives, code, visualizations, findings, and limitations. Conclusions will be based on actual analysis rather than assumed results.

## Planned notebooks

1. `01_data_quality_and_eda.ipynb` — dataset inspection and exploratory analysis
2. `02_customer_rfm_analysis.ipynb` — customer metrics and segmentation
3. `03_sales_forecasting.ipynb` — forecasting experiments and evaluation
